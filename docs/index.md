# FormatBook

FormatBook is a companion repository for [GWASLab](https://github.com/Cloufield/gwaslab). It collects JSON specifications that map tool-specific GWAS summary-statistics column names to GWASLab canonical headers.

## Contents

- **[Format summary](format_summary.html)** — interactive coverage heatmap showing which tier groups each format supports (variant ID, location, alleles, effect size, p-value, and more).
- **[Formats](formats/index.md)** — browse individual format pages with metadata, column mappings, and coverage details.
- **[Design](design.md)** — format JSON structure, canonical fields, and contribution guidelines.
- **[Auto presets](auto.md)** — documentation for `auto*.json` header-detection presets.
